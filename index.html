Not connected This device keeps its entries to itself.

Connect this device to your own sync address and every entry is carried between your computer and your phone by itself, within a few seconds. Type the same address and password on both. The app keeps working normally with no connection — whatever was typed offline is sent up the next time it reaches the internet.

Back up your data Do this every week

The app saves inside this browser on this computer. If the browser data is cleared, the entries go with it. Save a backup file to be safe — you can restore it here or on another computer. One backup file holds both books, so you only need to do this once.

Start over Affects the open book only

Erases every entry in the book you have open and starts it as a fresh 60-day trial. The other book is left alone. Save a backup first.

How to use this

  1. Set the trial start date at the top right. Everything else counts from there.
  2. Each evening open Daily Entry — the date and morning cash are already filled in for you. Type only the new numbers.
  3. Press Make PDF of this day and send it to the owner.
  4. On days 7, 14, 20, 30, 37, 44, 51 and 60, fill in Checkpoints before the meeting.
  5. On day 60, use PDF Reports → Full 60-day report for the final review.
